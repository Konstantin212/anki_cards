# Anki Deutsch: генератор карток

Проект створює колоду Anki для вивчення німецької (підручник **Begegnungen A2/B1**).
Користувач додає зображення списків слів у `Words/` → я їх розпізнаю, додаю переклад
українською + приклади речень і перезбираю колоду. Мова спілкування: українська.

## Робочий процес
1. Запускаю `python3 image_queue.py pending` і беру лише нові або змінені файли з `Words/`.
2. Переглядаю кожне зображення, розпізнаю німецькі слова в порядку читання та відкидаю заголовки, інструкції й номери вправ. OCR використовую як чернетку; звіряю умлаути, `ß`, артиклі, множину, `sich` і відокремлювані префікси.
3. Формую повні записи у `/tmp/anki_deutsch_candidates.json` за схемою нижче.
4. Перевіряю batch: `python3 merge_words.py --dry-run /tmp/anki_deutsch_candidates.json`.
5. Додаю записи: `python3 merge_words.py /tmp/anki_deutsch_candidates.json`. Скрипт пропускає дублікати щодо `words.json` і всередині batch. Порівняння прибирає `*` і `…`, стискає пробіли та ігнорує регістр.
6. Перезбираю пакет: `uv run --no-project --with genanki python build_apkg.py`.
7. Після успішної збірки позначаю використані файли: `python3 image_queue.py mark <шляхи>`.
8. Користувач імпортує `Deutsch_Begegnungen_A2_B1.apkg` в Anki. Фіксовані model/deck ID і guid від чистого слова оновлюють картки без дублікатів.

Не редагую `words.json` вручну під час звичайного імпорту. Не позначаю зображення опрацьованим, якщо не можу впевнено прочитати хоча б одну потрібну одиницю.

## Формат запису в words.json
```json
{
  "word":        "слово на першій стороні (голий іменник без артикля; інфінітив дієслова)",
  "full":        "der/die/das <Іменник>, <закінч. мн.> для іменників; \"\" для дієслів",
  "translation": "переклад українською",
  "forms":       "для дієслів: Perfekt: er hat/ist ... · Präteritum: er ...; інакше \"\"",
  "examples":    [["німецьке речення", "український переклад"]]
}
```

## Правила створення карток
- **Іменники**: `full` = артикль + слово + показник множини, як у підручнику
  (`der Übersetzer, -`; `die Frau, -en`). `forms` порожнє.
- **Дієслова**: завжди додавати `Perfekt` і `Präteritum` у поле `forms`. `full` порожнє.
- **Відокремлювані дієслова**: у полі `word` познач місце відокремлення зірочкою `*`
  між префіксом і основою: `auf*stehen`, `an*fangen`, `ein*nehmen`, `ab*schließen`,
  `um*ziehen`, `sich vor*stellen`. Невідокремлювані (префікси be-, ge-, er-, ver-, ent-,
  emp-, miss-, а також `sich unterhalten`, `sich befinden` тощо): не позначати.
  Перевірка: якщо в 3-й особі однини префікс іде в кінець речення (er steht **auf**),
  відокремлюване. Скрипт автоматично прибирає `*` для озвучення (поле `WordClean`).
- **Приклади**: 1–2 речення: німецьке + український переклад. Переклад курсивом робить шаблон.
- **Мовні шаблони / Redemittel** («Meiner Meinung nach …», «Ich bin dafür.»): за замовчуванням
  не роблю з них картки, але якщо користувач просить, додаю: `word` = німецька фраза
  (пропуски позначаю «…»), `full` і `forms` порожні, `examples` можна лишити порожнім
  (фраза сама є прикладом). Скрипт прибирає «…» і `*` для TTS/guid.

## Тип нотатки / шаблон
Власний тип **"Deutsch Wort"**, поля: `Word, Full, Translation, Forms,
ExampleDE1, ExampleUA1, ExampleDE2, ExampleUA2, WordClean`. Шаблон карток і стилі містяться
у `build_apkg.py`. Німецька озвучується вбудованим TTS Anki (`{{tts de_DE:...}}`),
окремі аудіофайли не потрібні.
